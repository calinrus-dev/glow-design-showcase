## Qué enseña esta publicación

Galería editorial de variantes y piezas visuales. Es una explicación del sistema, no una biblioteca descargable.

Se publican imágenes y criterios de diseño; los paquetes, tokens y efectos implementados permanecen privados.

## Guion del caso de estudio

Este guion sirve para explicar el recorrido documentado y preparar una demostración controlada. No afirma que se haya ejecutado completo durante esta publicación.

1. **Elegir una variante.** Observar: Piezas de interfaz que mantienen relaciones y jerarquía.
2. **Explorar un componente.** Observar: Lenguaje de color, tipografía y superficies.
3. **Comparar estados.** Observar: Comportamientos visuales que acompañan a los estados.
4. **Revisar coherencia.** Observar: Una experiencia de catálogo para comparar variantes.
